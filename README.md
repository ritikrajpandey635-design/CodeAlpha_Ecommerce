# 🛒 CodeAlpha E-Commerce Store

A simple and responsive E-Commerce Store developed as part of my **CodeAlpha Internship – Task 1**.

The project includes a frontend interface along with a Django backend for managing products, users, shopping cart, and orders.

## 🚀 Features

- 🛍️ Product Listing
- 🔍 Product Details
- 🛒 Add Products to Cart
- ➕ Update Cart Items
- ➖ Remove Items from Cart
- 👤 User Registration
- 🔐 User Login & Logout
- 📦 Order Processing
- 💾 Database Integration
- 📱 Responsive Design

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Django
- SQLite
